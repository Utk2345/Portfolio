# Folioframe delivery outcomes

- [x] **Portfolio homepage and featured work** — The site provides a portfolio homepage with a clear personal introduction and a featured work area that communicates the owner’s role, availability, and a way to contact them.
- [x] **Responsive project gallery** — The site presents projects in a consistent card-based gallery with responsive navigation and layouts optimized for desktop, tablet, and mobile.
- [x] **Project details and links** — Each project entry supports a title, description, visual thumbnail treatment, category/tags, and links to live work or source code.
- [x] **Owner project workflow** — The owner can add, edit, and remove project entries from the portfolio page, and saved entries persist for the current browser session.
- [x] **Dark mode toggle** — The portfolio includes a header toggle that switches between light and dark themes, persists the choice in the browser, and respects the system preference when no choice has been made.
- [x] **Contact form routing** — The site includes a contact form with name, email, and message fields, and the Contact, Let’s talk, and Start a conversation actions scroll to that form; submission prepares a mailto enquiry addressed to the portfolio email.
